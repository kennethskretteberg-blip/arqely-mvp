# Installer Varmeplan som app på Windows

Varmeplan kan installeres som egen app fra nettleseren. Det er fortsatt varmeplan.no — hver
oppdatering er på plass neste gang du åpner appen, uten installasjonsfil.

1. Åpne **varmeplan.no** i Microsoft Edge eller Chrome og logg inn.
2. Klikk **«Installer Varmeplan»** (i menyen øverst til høyre, under initialene dine), eller
   ⊕-ikonet («Installer app») ytterst til høyre i adresselinja.
3. Varmeplan ligger nå i Start-menyen og kan festes til oppgavelinja (høyreklikk → **Fest til
   oppgavelinjen**).

Åpner du Varmeplan fra Start-menyen mens appen allerede er åpen, hentes det åpne vinduet fram i
stedet for at det lages et nytt. Ingen nett → appen sier «Varmeplan trenger internett» og lar deg
prøve igjen; den viser aldri en gammel versjon.

Avinstallere: Windows-innstillinger → Apper → Varmeplan → Avinstaller (eller «⋯ → Avinstaller
Varmeplan» i appens eget vindu).
